# AutoCutStudio 🔵

**手势剪辑 + 智能水印工具** — 电商视频批量处理神器

双击打开即用，无需安装任何环境。

---

## ✨ 功能

### 👌 手势剪辑
- 把视频拖入 **待剪素材** 文件夹
- 自动识别 **👌 手势**（比 OK 手势）
- 手势消失后自动截取有效片段
- 支持 **监控模式** — 放进去自动剪

### 💧 智能水印
- 把视频拖入 **AI水印** 文件夹
- 自动叠加水印图片，原地替换
- **可视化预览** — 可拖拽调整水印位置
- 支持精细偏移调整（X/Y 像素级）
- 支持监控模式

### 📐 预览功能
- 选择参考视频，实时显示水印位置
- **鼠标拖拽水印**调整位置
- 坐标实时显示
- 支持 5 个预设位置（左上/右上/左下/右下/居中）

## 🚀 快速开始

1. **下载** — 从 Releases 下载 `AutoCutStudio.dmg` 或 `.app.zip`
2. **首次运行** — 双击 → 右键 "打开" → 点击 "打开"
3. **开始使用** — 选好水印图片和参数就能开始处理

### 基本流程

```
视频 → 待剪素材/ → 👌 手势识别 → 自动截取 → 加水印 → 成片
视频 → AI水印/      → 💧 自动加水印 → 原地替换
```

## ⚙️ 配置说明

### 水印设置
| 参数 | 说明 |
|------|------|
| 水印图片 | 支持 PNG（推荐透明背景） |
| 位置预设 | 5 个角落 + 居中 |
| X/Y 偏移 | 从边缘向内的像素距离 |
| 缩放 | 水印大小比例（5%~200%） |

### 手势剪辑设置
| 参数 | 说明 |
|------|------|
| 延迟 | 手势消失后等待秒数 |
| 保留时长 | 剪辑片段长度 |
| 自动加水印 | 剪辑后自动叠加水印 |

## 🛠️ 自行构建

如果你想自己编译或修改源码：

```bash
# 克隆仓库
git clone https://github.com/nxb-works/AutoCutStudio.git
cd AutoCutStudio

# 安装依赖
pip3 install pyinstaller

# 构建独立版 .app
python3 build_app.py
```

构建产物在 `dist/AutoCutStudio.app`。

## 🙋 常见问题
